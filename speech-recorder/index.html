Speech Recorder

A minimal Android app for long, hands-free dictation. One tap starts recording from a Bluetooth headset's microphone, and it keeps recording with the screen off and the phone in a pocket.

  • Audio is saved in one-minute segments, so a crash loses at most the minute in progress.
  • Once connected to Google Drive, each finished segment is uploaded to a Speech Recorder folder in your own Drive, and removed from the phone only after Drive confirms an exact copy.
  • An alarm sounds whenever recording is at risk: the headset is lost, the microphone goes silent, storage runs low, or the app is stopped.

Download the latest APK (Android 13 or later). Earlier signed builds are on the releases page.

Prompt scripts

Instead of dictating freely, the app can read a prompt script aloud one prompt at a time and record your answer to each. A script is a small JSON file: a title and a list of prompts. Import it from a file on the phone or from an https address, and the app saves it, speaks each prompt, and records a take per answer. Each recording's manifest says which take answers which prompt, so a tool can file and transcribe it without anyone listening.

  • Have an AI agent write one. Point your agent at script-prompt.md. It says what to ask you first, every rule the importer enforces, and how to hand the file over.
  • Write one by hand or build a tool. The specification is the full contract. It has the prompt script schema, the manifest schema, the audio format and examples.
